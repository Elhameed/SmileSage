# SmileSage

SmileSage is a cross-platform dental health app designed to help users monitor their oral health, find nearby clinics, learn about dental care, and receive personalized reminders. The app leverages machine learning for dental scan analysis and offers a user-friendly experience on android mobile platforms.

---

## 🚀 Project Overview
SmileSage empowers users to:
- Scan their teeth and receive instant analysis using a server deployed ML model
- Track and manage streaks for daily brushing, with badges awarded for consistency
- Generate and download personalized PDF reports of their scan results
- Find and view details of nearby dental clinics on a map
- Access educational content and dental care tips
- Set reminders for brushing, flossing, and dental visits
- Manage their profile and preferences
- Use the app in multiple languages

## 🛠️ Installation & Setup

### Prerequisites
- [Flutter](https://flutter.dev/docs/get-started/install) (version as specified in `pubspec.yaml`)
- Dart SDK (bundled with Flutter)
- Platform-specific requirements (Android Studio/Xcode for mobile, etc.)

### Step-by-Step Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Elhameed/SmileSage.git
   cd smilesage
   ```
2. **Install dependencies:**
   ```bash
   flutter pub get
   ```
3. **Run the app:**
   ```bash
   flutter run
   ```

> For detailed setup instructions, see the [Flutter documentation](https://flutter.dev/docs/get-started/install) and platform-specific notes in the `/docs` folder.

## ✨ Features
- **Dental Scan & Analysis:** Scan teeth and get instant results using a server-deployed ML model.
- **Daily Brushing Streak Tracking:** Track your daily brushing habits and maintain streaks for better oral hygiene.
- **Badge Awarding System:** Earn badges as rewards for maintaining brushing streaks and achieving milestones.
- **PDF Generation:** Generate and download personalized PDF reports of your scan results and brushing progress.
- **Clinic Finder:** Locate and view details of nearby dental clinics on an interactive map.
- **Educational Content:** Access articles, tips, and guides on dental care.
- **Reminders & Notifications:** Set and receive reminders for oral hygiene routines.
- **Profile Management:** Manage user information and preferences.
- **Multi-language Support:** Use the app in English, French, Swahili, and Kinyarwanda.
- **Cross-Platform:** Available on Android mobile devices.
